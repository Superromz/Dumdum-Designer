# Sketch a Page: Plan It Before You Design It

**Command:** `/dumdum-designer:sketch-page`

## What It Does and Why

Most pages go wrong before anyone picks a color: they try to do too many things, or the important part ends up at the bottom. This skill helps you decide what the page is for and what goes on it, before any designing happens.

It asks a few simple questions, one at a time: which page, the one thing you want visitors to do, who's visiting and where they come from, and what has to be on it. If you're not sure, it suggests what pages like yours usually have, and you add, remove or reorder.

If your project already has an app, it looks at the existing pages first, so the new page uses the same menu and footer.

## What You Get

A page plan saved in `design/pages/<page>.md` with:

- the page's one job, in a sentence;
- the sections in order, each with draft headlines and button words (real words, not filler);
- a rough sketch of the layout, and how it changes on a phone;
- anything still to decide, marked in brackets like `[your price here]`.

## Good to Know

- Nothing gets built here. The plan is what `/dumdum-designer:make-prototype` builds from.
- You can edit the plan file yourself. It's plain text.
